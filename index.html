Long multiplication (the paper method)

Shift-and-add is ordinary long multiplication in base 2. Write M once for every bit of Q, shifted one place further left each time; where the Q bit is 0, write zeros instead. Adding the rows gives the product. Cycle c handles bit c−1 of the original Q (after c−1 right shifts it has become Q₀), the shifted M in the step table is exactly that row, and P is the running sum.

How shift-and-add multiplication works

Shift-and-add is the long multiplication you learned at school, done in base 2. In base 2 every digit of the multiplier is 0 or 1, so each row of the paper method is either M itself (shifted) or all zeros. A processor without a multiply instruction can therefore multiply using only add and shift.

It uses these registers for n-bit unsigned operands:

  • M: the multiplicand, held in a 2n-bit register so it can be shifted left n times without losing bits.
  • Q: the multiplier (n bits). Its lowest bit Q₀ decides each step, and it is shifted right so the next bit becomes Q₀.
  • P: the product (2n bits), starts at 0.
  • Count: starts at n, one cycle per multiplier bit.

Every cycle does the same three things:

Q₀ActionThen
1P = P + Mshift M left 1 (M × 2), shift Q right 1 (logical), Count = Count − 1
0no add

After n cycles Count = 0 and P holds the product. In cycle c, M has been doubled c − 1 times, so it equals M × 2c−1, which is exactly the weight of bit c − 1 of the multiplier. Adding it whenever that bit is 1 gives P = Σ qi · M · 2i = M × Q.

Example, 13 × 11 at 4 bits: Q = 1011. Bits 0, 1 and 3 are 1, so P = 13 + 26 + 104 = 143 (bit 2 is 0, so 52 is skipped).

Why it never overflows: the largest n-bit number is 2n − 1, and (2n − 1)2 = 22n − 2n+1 + 1, which is less than 22n. So a 2n-bit P always holds the whole product. In 8086 assembly, P is 32 bits split over two 16-bit registers, so each 32-bit add is ADD (low words) followed by ADC (high words plus the carry).

8086 assembly: multiplication without MUL

The same algorithm as the simulator, for 16-bit numbers, written with only ADD/ADC, SHL/RCL, SHR and TEST. Neither program uses MUL or IMUL anywhere, not even for printing (decimal output divides by 10 with DIV).

  • mul16.asm (NASM, 32-bit Linux): prints the inputs, a 16-line step table and the product. To run it: open onecompiler.com/assembly, delete the sample code, paste the program (use Copy below) and press Run. Change the inputs in the two dw lines at the top.
  • mul16_8086.asm (MASM/TASM, 8086 lab-manual style): open it in emu8086 and press Emulate → Run, or assemble it in DOSBox with MASM + LINK. It stores the product in PROD_HI:PROD_LO and prints it in hex.
