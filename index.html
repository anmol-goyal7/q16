Long multiplication (the paper method)

Shift-and-add is ordinary long multiplication in base 2. Write M once for every bit of Q, shifted one place further left each time; where the Q bit is 0, write zeros instead. Adding the rows gives the product. Cycle c handles bit c−1 of the original Q (after c−1 right shifts it has become Q₀), the shifted M in the step table is exactly that row, and P is the running sum.
